# Sweet Dreams Core [UE Plugin]
## What is this project?
Sweet Dreams Core is a **fully C++-based framework plugin** for Unreal Engine, designed to help developers build games **faster**, **more efficiently**, and with a **solid architecture**. Every system is designed to be **scalable, extensible, and 100% data-driven**, making it suitable for projects of any genre or scope.

The name "Sweet Dreams" comes from a goal: let you sleep peacefully instead of staying up fixing spaghetti logic.

## Features
### 🧠 Core Subsystem
- Robust **save/load manager**
- **Debugging tools** for runtime inspection
- Static Blueprint functions to help develop games faster
### ⚙️ Game Mode
- Replicated loading screen
- Level streaming and seamless loading
- Multiplayer and session functions
### 🕹️ Player Controller & Character
- Easy movement, run and camera functions
### 🧾 Widget & HUD Manager
- HUD actor manages all UIs for every PlayerController
- Auto-creates and **switches visibility** of widgets
### 💬 Dialogue System (Data-Driven)
- Branching dialogue via **Data Assets**
- Support for **choices, sequences, and scripted events**
- Native **Widget integration** with simple binding
- Blueprint triggers for dialogue events
### 🎒 Inventory & Items
- Modular **inventory component per actor**
- **Equippable**, **usable**, and **inspectable** items via Data Assets
- Works for player, NPCs, and containers
- Multiplayer-friendly
### 🎥 Render Actor System
- Scene setup made easy: toggle **fog**, **sky**, **post-process**, **sun**, and **exposure** at runtime
- Ideal for **cutscenes**, **showcases**, or environment iteration
- Use one actor to manage scene lighting presets
### 🎥 Multicamera Component
- One actor, one camera, multiple possibilities
- Instantly **switch position and rotation** presets
- Great for cinematics, combat views, or multi-POV gameplay
